\begin{abstract}%%%%%%%%%%%%% 概要 %%%%%%%%
% プライバシーに配慮した高齢者見守りに向け，音響イベント検出の実環境適用を目指す．
% 本稿では，モデルパラメータを増大させずに精度を向上させるため，信頼度を用いた半教師あり学習を改良し，ドメイン汎化手法のアーキテクチャを検討した後，後処理手法含む三手法を統合した．
% 実験の結果，モデル規模を維持したまま先行研究を上回る精度を達成し，提案手法の有効性を確認した．
プライバシーに配慮した高齢者見守りに向け，音響イベント検出の実環境適用を目指す．
本研究では，モデルパラメータを増大させずに精度を向上させるため，信頼度を用いた半教師あり学習とドメイン汎化手法のアーキテクチャを改良し，統合した．
実験の結果，モデル規模を維持したまま先行実装を上回る精度を達成した．また，部分的に先行研究から精度を向上した．これらの結果から，提案手法の有効性を確認した．
\end{abstract}
